Write a HTML code which will divide web page in three frames. First frame should consists of company name as heading. Second frame should consists of name of departments with hyperlink. Once click on any department, it should display information of that department in third frame.

<!DOCTYPE html>
<html>
<head>
    <title>Company Frameset</title>
</head>

<frameset rows="20%,*">
    <!-- Top Frame -->
    <frame src="header.html" name="headerFrame">

    <frameset cols="30%,*">
        <!-- Left Menu -->
        <frame src="menu.html" name="menuFrame">

        <!-- Right Content -->
        <frame src="welcome.html" name="contentFrame">
    </frameset>
</frameset>

</html>

✅ 4) Queries
a) List all products in the inventory
db.products.find({}, { name: 1, price: 1, _id: 0 });

b) List orders with value > 20000
db.orders.find({ total: { $gt: 20000 } });

c) List all orders that are NOT processed (invoice not generated)
db.orders.aggregate([
  {
    $lookup: {
      from: "invoices",
      localField: "_id",
      foreignField: "order_id",
      as: "invoice"
    }
  },
  { $match: { invoice: { $size: 0 } }}
]);

d) List all orders with invoice for customer "Mr. Rajiv"
db.orders.aggregate([
